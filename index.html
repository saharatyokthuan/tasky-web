Zero dependencies · Pure standard library

Stay on task, stay in the terminal.

Tasky is a tiny command-line task manager. Add, list, and finish tasks in seconds — no account, no cloud, just a JSON file you own.

Get started See features
~/projects — tasky 
$ tasky add "write landing page"
added: [ ]   1  write landing page
$ tasky add "ship it"
added: [ ]   2  ship it
$ tasky done 1
done: [x]   1  write landing page
$ tasky list
[ ]   2  ship it
▌

Everything you need, nothing you don't

Five subcommands. One file. That's the whole thing.

  • ⚡

    Fast

    Starts instantly, no runtime or network calls. Pure standard library.

  • 📦

    Portable

    One pip install and it runs anywhere Python does.

  • 🔒

    Yours

    Tasks live in a plain JSON file under $XDG_DATA_HOME.

  • 🧩

    Composable

    Pipe the store into jq, grep, or your own scripts.

Three steps to a clearer day

  1. 1

    Capture

    Dump a thought the moment it appears with tasky add.

  2. 2

    Focus

    tasky list shows only what's left to do.

  3. 3

    Finish

    Knock it out with tasky done and move on.

Install in one line

Requires Python 3.10 or newer.

python -m pip install tasky

Fewer tabs. More done.
